# Flux Canvas — use cases

Open the canvas home with **☰** or **H**. "Start something" gives an empty version of each use case. **Examples** opens a worked one. Examples are signed by three example authors (**Ana, Ben, Chen**) so you can see collaboration in action without anyone else online. Each opens as a new canvas you can keep and remix.

| Use case | Template | Example | What to try |
|---|---|---|---|
| **Brainstorming** | Brainstorm | *Team offsite — brainstorm and vote* | Double-click empty space for a note (select mode, `V`). Select notes and press `D` to dot-vote (budget in the title bar). ⌘K → *Start timer*. With several selected: *Sort by votes*, *Arrange in a grid*, *Cluster into a frame*. |
| **Idea building** | Mind map | (any mind map, or paste an outline) | Select a topic: `Tab` adds a child while typing, `Alt+arrow` adds one in a direction, and the `+` handles connect by drag. `L` tidies the tree. Paste an indented list to grow a whole map. |
| **Connecting thoughts** | any | *Expense approval* | Select a connector, then **⇄** to mark it *supports*, *contradicts*, *leads to*, *depends on*, *example of* or *question*. Change its shape (curve, straight, elbow) and dash. |
| **Feedback collecting** | Feedback board | *Sprint 42 retro* | Notes go in columns (frames). Votes and reactions (👍 💡 ❤️ ❓ ⚠️) show as chips; click a chip to add or take back yours. `⇧S` gives a Markdown summary: top voted, each column ranked, open threads. |
| **Story building** | Storyboard | *Onboarding story — Maya's first week* | Scenes are frames connected left to right. `F5` presents them in connector order: ← → Space, Esc ends. Comment on a scene to discuss it. |
| **Moodboards** | Moodboard | *Brand refresh — moodboard* | Drop or paste images. Select one and click **🎨** to extract a five-colour palette as swatches. Select several and click **▥** for a masonry layout. React with ❤️ and decide in a comment thread. |
| **Auditing flows** | Audit flow | *Expense approval — audited flow* | Select the first step and press `A`. Walk the flow with `1` pass, `2` fail, `3` needs info, and a note. The report gives a table plus failing and open steps. *Sign off* fences all your verdicts into one signed record. `⇧H` replays the whole canvas history. |
| **Wireframing** | Wireframe | — | Shapes size themselves to their labels. Use snapping and align/distribute in the selection toolbar. |

## Why signed records matter for each

- **Brainstorm and feedback:** every note, vote and reaction names its author. "Who voted for what" is checkable, not just claimed.
- **Story and moodboard:** each contribution and each decision in a thread is attributable. Export as SVG or `.flux` without losing provenance.
- **Audit:** a sign-off is one signature over the exact verdicts it covers. Change or forge a single verdict and the fence no longer verifies. The history scrubber shows what the canvas looked like at any point.
