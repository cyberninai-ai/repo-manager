    Keyboard shortcuts

    Every stroke is a signed pattern. The canvas is the union of its records. Nothing here is a file until you export it.

    Pen down + moveFreehand stroke
    Shift + dragRectangle
    Alt + dragCircle
    Drag from an element's edgeArrow, bound to both elements by CID
    T · the Text tool · double-tapText. Double-tap your own text (or Enter on it) to edit it
    N · the Shapes and cards toolPick a kind in the style bar, then place a card, mind-map topic, flowchart shape, sticky or wireframe piece. It sizes itself to its label
    “+” handles on a selected nodeClick: new connected node in that direction. Drag: to another element to connect it, or to empty space for a new node there
    While typing a node labelEnter saves · Tab saves and adds a child · ⌘/Ctrl+Enter saves and adds a sibling
    M · the Comment toolComment: click an element to pin it there (it follows the element) or empty space. Threads, replies and resolve live in the comments panel
    Drop / paste an image (or ⌘K → Insert image)Image. Draw on it right away with the pen. To move or resize it, switch to select mode (V), drag it, or pull the corner handle
    V · P · Space · ESelect · Draw · Hand (hold Space with any tool) · Eraser. Esc returns to Select from the shape and hand tools
    Rectangle · Ellipse · Line toolsDrag to draw; you are back in Select with the new shape selected. A line dragged from one element to another becomes a bound connector
    Ctrl/⌘ + dragLasso from pen mode; Ctrl/⌘-drag inside the selection moves it
    Space + drag · wheel · pinchPan · ctrl+wheel or pinch to zoom
    ⌘Z / ⇧⌘ZUndo / redo — your own records only
    DeleteRevoke selection (-N-1, only your own)
    ⌘G / ⇧⌘GGroup / ungroup
    ⌘V a patternImport signed records from the clipboard
    ` (backtick)Ledger
    ⌘K or /Command palette

    Keyboard only

    Tab / Shift+TabStep through elements; each is announced. Tab past the last one leaves the canvas
    Arrow keys (Shift = ×10)Move the selection, or pan when nothing is selected
    Delete / BackspaceRevoke the selection
    + / −Resize a selected image, otherwise zoom
    R · O · T · IInsert rectangle · circle · text · image at the centre
    CConnect the two selected elements with an arrow (first → second)
    Alt + arrow · ⌘/Ctrl + Enter · EnterOn a selected node: new connected child in that direction · new sibling · edit its label
    N · LDiagram tool · tidy the selected node's diagram
    Drag a comment pin · “move pin” in its threadMove the pin (arrow keys after “move pin”, Enter when done). A pin on an element keeps following it
    M · EnterComment on the selection (or the centre) · edit the selected text if it's yours
    [ · ]Brush thinner · thicker (bottom bar slider, 1–80). With your lines selected, restyles them too
    { · }Text smaller · bigger (10–400): resizes your selected text, otherwise new text
    Colour swatchColour for new work; also recolours your selected strokes, shapes, arrows and text
    ⌘C · ⌘X · ⌘V · ⌘DCopy · cut · paste (at the pointer) · duplicate. Alt-drag a selection to duplicate it
    EEraser: wipe across your own elements (each is revoked, undo brings it back)
    ⌘⇧↑ · ⌘⇧↓ · ⌘⇧LBring to front · send to back · lock or unlock (locked elements can be drawn over but not moved)
    DraggingSnaps to the edges and centres of nearby elements; press ⌘/Ctrl during the drag to place freely
    Paste an indented listBecomes a connected mind map (also ⌘K → Mind map from outline)
    H · the menu buttonCanvas home: your canvases, templates and worked examples
    Double-click empty space (select mode)A sticky note, ready to type
    D · vote and react on the selection toolbarDot-vote the selection (within your vote budget) · react with 👍 💡 ❤️ ❓ ⚠️. Click a chip under a note to toggle yours
    ⇧SSummary of notes, votes, reactions and comments as Markdown
    F5 · ⇧PPresent frames as a story (← → Space, Esc to end)
    AAudit the flow from the selected step: 1 pass · 2 fail · 3 needs info, then sign off
    ⇧HHistory: replay the canvas record by record (read-only)
    Esc · 0Clear selection · zoom to fit
